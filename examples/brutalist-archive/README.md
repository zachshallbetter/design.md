# Brutalist Archive

A rigid, high-contrast design system inspired by raw industrial print and architecture. Demonstrates the use of **Hypertokens** to package thick borders, zero-radius shapes, and offset shadows into reusable presets.

## Files

| File | Description |
|------|-------------|
| `DESIGN.md` | The complete design system specification, containing the YAML frontmatter (with the custom `hypertokens` section) and the markdown body sections. |
| `design_tokens.json` | The exported design tokens in the W3C DTCG format. |
| `tailwind.config.js` | A Tailwind CSS v3 theme configuration derived from the design tokens in the DESIGN.md frontmatter. |
